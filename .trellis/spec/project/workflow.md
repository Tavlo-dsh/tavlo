# 开发与文档约定

- **关键功能用 TDD**：先写失败用例，再实现。可测的纯逻辑放在 `src-tauri/src/*.rs` 的单测里（`pnpm test:shell`）；只有必须操作真实窗口的接线才留在 `lib.rs`。
- **参考其他实现时搬契约，不搬代码**：读懂对方测试断言的产品契约（文件名、文案、按钮、尺寸），用这些契约在本仓库写失败用例，再实现。不把依赖 Electron 的测试原样拷进来。
- **文档只写优先级**（P0 / P1 / P2），不写排期、里程碑和日期计划。
- **同一事实只写一处**：持久规则写在 `.trellis/spec/`，调研写在 `.trellis/research/`，对外介绍写在 `README.md`，不在多处重复。
- **AGENTS.md** 只有在用户提出要求、并且同意具体改动后才能修改。
